# 🚀 Shaik Sohel — Personal Portfolio

[![GitHub Pages](https://img.shields.io/badge/Deploy-GitHub%20Pages-blue?logo=github)](https://thisissohel07.github.io/portfolio/)
[![Netlify](https://img.shields.io/badge/Deploy-Netlify-00C7B7?logo=netlify&logoColor=white)](https://netlify.com)
[![Vercel](https://img.shields.io/badge/Deploy-Vercel-000000?logo=vercel&logoColor=white)](https://vercel.com)

A stunning, premium-quality, fully responsive personal portfolio website with a futuristic UI, glassmorphism design, and smooth animations.

---

## ✨ Features

- 🎨 **Premium Dark & Light Theme** — Toggle between beautiful dark and light modes with theme memory
- 🌌 **Particles.js Background** — Interactive animated particles in the hero section
- ⌨️ **Typed.js Animation** — Dynamic typing effect showcasing roles and skills
- 🎬 **GSAP + ScrollTrigger** — Smooth scroll-based animations and parallax effects
- 📱 **Fully Responsive** — Mobile-first design that looks great on all devices
- 🪟 **Glassmorphism & Neumorphism** — Modern card designs with frosted glass effects
- 🖱️ **Custom Cursor & Mouse Glow** — Interactive cursor effects for desktop
- 📊 **Animated Counters** — Statistics that animate when scrolled into view
- 🏗️ **3D Card Effects** — Vanilla Tilt.js for interactive card hover effects
- 📜 **Scroll Progress Bar** — Visual indicator of page scroll position
- 🎯 **Active Nav Highlighting** — Navbar links highlight based on current section
- 📬 **Contact Form** — Beautiful glassmorphism form with validation
- 🗺️ **Google Maps Integration** — Embedded map showing location
- 📲 **WhatsApp, Email & Call Buttons** — Quick action buttons for contact
- ♿ **Accessible** — ARIA labels, semantic HTML, reduced-motion support
- 🔍 **SEO Optimized** — Meta tags, Open Graph, semantic headings

## 🚀 Quick Start

### Option 1 — Open Directly
Simply open `index.html` in your browser. No build tools needed!

### Option 2 — Local Server
```bash
# Using Python
python -m http.server 8000

# Using Node.js (npx)
npx serve .

# Using VS Code
# Install "Live Server" extension and click "Go Live"
```

## 🌐 Deployment

### GitHub Pages
1. Push the repository to GitHub
2. Go to **Settings → Pages**
3. Select the branch (e.g., `main`) and root folder
4. Your site will be live at `https://<username>.github.io/<repo>`

### Netlify
1. Log in to [Netlify](https://netlify.com)
2. Drag and drop the project folder, or connect your GitHub repo
3. Your site deploys automatically

### Vercel
1. Log in to [Vercel](https://vercel.com)
2. Import the GitHub repository
3. Deploy with zero configuration

## 🎨 Customization

### Change Theme Colors
Edit the CSS variables in `css/style.css`:
```css
:root {
    --primary: #6c63ff;
    --secondary: #00d4ff;
    --accent: #ff6b9d;
    /* ... */
}
```

### Update Typed.js Strings
Edit `js/typing.js`:
```javascript
strings: ['Your Role 1', 'Your Role 2', 'Your Role 3']
```

### Update Personal Info
Edit the content directly in `index.html`.
